# IBM Cloud Pak for Business Automation 26.0.0 on Certified Kubernetes

This repository includes folders and resources to help you install the IBM Cloud Pak for Business Automation capabilities. Installation of the capabilities is done with the Cloud Pak operators.


## Documentation

For information and instructions on how to install, manage, and administer Cloud Pak for Business Automation, go to [IBM Docs](https://www.ibm.com/docs/SSYHZ8_26.0.0).

## Important Configuration Guides

- **[ADP Gitgateway and DICMS Database Configuration](ADP_DICMS_PG.md)** - Database configuration support matrix for v26.0.0 GA, including fresh install and upgrade scenarios for ADP Gitgateway and DICMS (Designer and Runtime) with PostgreSQL.
